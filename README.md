# BetterChzzk

치지직 시청 경험을 개선하는 Chrome 확장 프로그램

## 기능

### 🚀 자동 배속 (지연시간 따라잡기)
- 설정한 지연시간 초과 시 자동으로 배속 재생
- 버퍼 끝에 도달하면 정상 속도로 복귀
- 팝업에서 활성화/비활성화, 시작 지연시간, 재생 속도 설정 가능

### ⏱️ 레이턴시 표시
- 채팅창에 현재 지연시간 실시간 표시

### 🔊 마우스 휠 볼륨 조절
- 영상 위에서 마우스 휠로 볼륨 조절
- 볼륨 오버레이 표시

### 🎁 포인트 자동 클릭
- 포인트 획득 버튼 자동 클릭

## 설치

1. 이 저장소를 클론하거나 다운로드
2. Chrome에서 `chrome://extensions` 접속
3. "개발자 모드" 활성화
4. "압축해제된 확장 프로그램을 로드합니다" 클릭
5. 다운로드한 폴더 선택

## 사용법

1. 치지직 방송 페이지 접속
2. 브라우저 툴바의 BetterChzzk 아이콘 클릭
3. 원하는 설정 조정

## 파일 구조

```
BetterChzzk/
├── icon/               # 확장 아이콘
├── popup/              # 팝업 UI
├── scripts/
│   ├── background.js   # 서비스 워커
│   ├── content-script.js # 설정 전달
│   └── inject.js       # 메인 로직 (MAIN 월드)
└── manifest.json
```
